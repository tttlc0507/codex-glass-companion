# Changelog

## 1.4.0 — 2026-11-02

First public preview, following local prototypes.

- Floating three-control AppKit capsule with native frosted/available Liquid Glass material.
- Five-hour and weekly remaining-allowance panels; local task status and plan steps.
- Gentle red/yellow/green diffusion, shorter highlight, and translucent hover feedback.
- Persistent light, dark and system appearances; rounded material/content masks.
- Optional per-user, event-driven follow-Codex launch integration and removal commands.
- Standard Codex/ChatGPT app and CLI discovery, optional database-column compatibility, local timezone reset display, and graceful unavailable states.
- Separate offline demo mode, universal release packaging, checksums, CI and contribution docs.

Known limits: Chinese UI; local Codex interfaces may change; some permission dialogs are not recorded; distribution is not notarized. See the README for the current compatibility scope.
