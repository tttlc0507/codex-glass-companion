First public preview of **Codex Glass Companion** — a floating glass capsule for Codex on macOS.

- Hover for five-hour and weekly remaining allowance and reset times.
- Follow local tasks with subtle red/yellow/green activity light.
- Switch between light glass, dark glass and system appearance.
- Optional per-user startup that follows Codex, plus disable/uninstall commands.
- Offline demo and source build available; no third-party Python packages.

**Requirements:** macOS 14+, Python 3.9+, and a signed-in Codex desktop app or CLI for live data. Native Liquid Glass needs macOS 26. The UI is currently Simplified Chinese.

Download the universal ZIP and SHA256SUMS below, verify the checksum, then open the extracted app. Read INSTALL.md before enabling follow-Codex startup.

**Preview limitations:** ad-hoc signed, not notarized; Codex local interfaces can change; some system confirmation dialogs may not be reflected in the activity light. Unofficial community project, not affiliated with OpenAI or Apple.

Please report your macOS/Codex version and a sanitized reproduction in Issues. Do not attach authentication files or private conversation logs.
